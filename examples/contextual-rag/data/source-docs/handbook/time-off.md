# Time off

Tlaltipac runs an unlimited paid time off policy with a few opinionated
guardrails so that unlimited does not collapse into "nobody takes any".

## Annual minimum

Every full-time employee takes at least twenty paid days off per year.
The minimum is tracked in the company HR tool and surfaced on the
manager's quarterly dashboard. Anyone trending below the minimum mid-year
gets a friendly reminder from their manager.

## Requesting time off

File the request at least two weeks before the start date for any
absence longer than a single day. Same-day or next-day absences only
need a Slack note to your manager and your team channel.

The request automatically blocks the calendar of anyone who is part of
an overlapping on-call rotation; the on-call schedule needs to be
re-balanced before the request is approved.

## Public holidays

Tlaltipac observes the national public holidays of each employee's
country of residence. The holiday list is maintained in the HR tool
and refreshed every December for the following year.

If you celebrate a holiday that is not on the list — for example a
religious observance — file a time-off request as usual; there is no
expectation that you justify it.
